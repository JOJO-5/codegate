# v0.1.37

手机与桌面工作台整理：已有会话优先，项目管理渐进展开，直接展示 CLI 对话与主 Agent 调度两种执行方式。采用低饱和蓝灰配色、统一字号与留白，减少首屏操作竞争。

修复窄屏文件选择器溢出、项目网格错位、表单控件样式不一致、新建任务焦点被顶栏遮挡和取消后的焦点返回。设备在线、会话运行与缓存待确认分开显示；设备、项目、会话及审计读取失败不再伪装为空数据。

设计心理学落实：按继续工作、创建、管理建立层级；错误保留原因与恢复入口；取消后返回原入口；保持任务状态与执行结果可核对。

验证：前端 UX 回归与类型检查/构建通过；Server 与嵌入 Web UI 测试通过。此前本轮完成浅/深主题、四种宽度、七类页面的 56 组隔离浏览器检查及关键键盘/恢复路径检查，详见 [界面审查报告](UX-AUDIT-NORMAN-2026-10-19.md)。真实手机软键盘、人工读屏和生产模型任务链路尚未验收。

打包包含嵌入前端的 Server 与六个平台的 Agent；Agent 运行逻辑未改动。该版本打包和 tag 发布不代表生产服务已部署。
