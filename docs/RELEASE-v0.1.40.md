# v0.1.40

会话页新增“恢复原对话”：选中已结束的会话后，可在当前页重新启动已授权的 CLI、加载保存的原生历史，也可继续切换其他会话。普通终端明确说明不支持原生对话恢复。

修复选择已关闭会话后侧栏消失、无法选择其他会话的问题；旧终端已经移除时，detach 的“会话不存在”不再阻塞后续切换。已有运行会话无需等待历史摘要读取完成即可接回；滞后或延迟响应不会把已结束的终端重新显示为运行中。

恢复失败保留历史列表和选择，可原地重试或返回；读取历史失败提供单独重试入口。重复点击防重，切换来源后的旧回包不会跳回旧对话。刷新和断线后只接回原进程，不重复启动恢复。已结束会话停止依赖存活终端的额度查询，避免无用报错。手机侧栏支持焦点转移、Escape 返回及窄屏布局。

设计心理学：明确区分“终端已结束”和“原生历史可恢复”，显示真实等待和失败状态，保留选择与切换控制权。

验证：Go Agent、Server、Protocol 测试和 vet，前端回归、类型检查、生产构建，以及 27 项隔离浏览器检查通过。真实 Codex 0.163.0 在独立目录完成保存历史、关闭终端、恢复同一原生对话、重复恢复复用、缺失历史拒绝的验证；外部模型调用为 0。Claude/OpenCode/DSH 的真实历史恢复及线上真实用户对话恢复未作为本次验收结论。

无数据库迁移、无 Agent 行为改动；需要更新 Server 与 Web。本机 Agent 遵循空闲升级，不中断运行会话。详见[修复与验收记录](FIX-SESSION-RECOVERY-2026-10-23.md)。
