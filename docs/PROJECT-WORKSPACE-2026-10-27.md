# 项目工作入口与任务中心：本地实现及验收

日期：2026-10-27。基线为 v0.1.45，属于[后续工作空间计划](UX-WORKSPACE-CHAT-PLAN-2026-10-26.md)的工作入口阶段。本批改动纳入本地 v0.1.46 标签，按用户要求暂不推送、构建发布镜像或部署。

## 用户路径

项目列表 → 进入项目 → 继续已有终端、恢复原对话或开始工作 → 查看改动与核对结果。项目内“后台任务”进入已限定设备和目录的任务列表；全局“任务”查看各设备的预约、续跑与主 Agent 调度。

- 项目卡片只保留“进入项目”主入口，离线项目仍可进入查看记录。项目内集中会话、改动、设置和可撤销移除入口。
- 最近工作桌面默认三项、手机默认一项；可主动展开，最多查看最近十五项。仓库发现在“添加项目”中主动触发，首页不自动扫描。
- 项目启动沿用已有 CLI 与主 Agent 两种执行方式，没有添加尚未实现的 Chat。后续同批增加了 [CLI 原生启动模式预选](NATIVE-CLI-MODES-AND-CHAT-2026-10-27.md)，直接映射原生启动参数。启动、恢复、文件和 Git 导航保留来源项目上下文；原设备入口仍可用。
- 全局导航整理为“项目 / 任务 / 设备”，设置和主题等放入同一工具菜单；手机列表页使用底部导航，进入项目后隐藏全局底栏，保留“所有项目”返回入口。
- 设备页提供统一任务入口，原有历史管理按需展开；旧 `#device-tasks` 链接仍能打开续跑历史、删除与撤销功能。

## 状态与恢复约定

任务中心读取原有 Server 记录，不创建第二份执行任务，不改变派发权限或费用策略。来源类型、设备和目录保持独立，列表按二十项分页；服务端列表上限不能解释成全部历史。

“进行中 / 需要处理 / 已预约 / 历史”按任务语义分类：执行失败、未知状态、需要确认和交付待验收归入需要处理；自动交付不视为用户验收。取消直接调用现有受权接口，区分正在请求、等待 Agent 确认及回执不明；不自动重发，保留代码和证据。

部分来源失败保留另一来源和上次结果，显示数量不完整。错误格式不变成空列表。取消会使早于取消的轮询失效；退出/切换账号清空聚合数据，旧响应不能回写。筛选和搜索在当前账号的标签页内保存，项目内容分区可在刷新后恢复。

项目会话刷新失败时保留记录，但旧的实时标记不能继续授权“接回”；刷新成功后恢复。缓存、离线和空数据分别表述，未通过实时确认时提示刷新，而不重复创建终端。

## 设计心理学落实

用“进入项目 / 开始工作 / 恢复原对话 / 查看过程与结果”对应用户目标，减少首页并列操作。高级内容在当前任务中展开，保留现有配色和克制层级。等待、失败与取消回执有文字反馈；移除入口可撤销，关闭启动面板不会被表达成任务已停止。

## 验证证据与限制

- 回归先确认旧项目卡片缺少工作空间入口，以及刷新失败后仍复用旧实时标记的问题，再实现修复。
- `npm run test:ux`：含新增目录边界、任务分类、部分失败、取消竞态、账号重置与数据格式检查。
- `npm run test:conversations`：原对话恢复、切换、旧回包、输入保护及来源项目返回检查。
- `npm run test:transfer`：上传与粘贴图片回归通过。
- `npm run build`：Vue 类型检查和生产构建通过。
- 隔离浏览器共 102 项检查：主流程 55 项；深色、减少动效、短屏及恢复矩阵 43 项；文件/Git/终端返回上下文 4 项。覆盖 320/390/430/640/768/1024/1440px、键盘焦点、离线、真实空数据、部分失败、取消未确认、刷新和旧历史入口。人工查看了手机、桌面和深色截图。
- 浏览器使用本地模拟 HTTP/WebSocket；创建、恢复和取消只作用于虚构任务，没有连接生产 Agent、修改用户项目或发起模型请求。截图保存在本地验收目录，没有提交用户数据。
- 真实 Android/iPhone 软键盘与触摸、实际浏览器 200% 缩放和读屏、真实 Agent 的全链路及线上验收尚未完成，不能称为实机或线上验收通过。

本地 v0.1.46 同时收录原生启动模式预选和此前的额度查询修复，不包含生产 Chat，也没有定位或修复 OpenCode 自身卡顿。额度查询仍待有效凭据验收；Chat 需先完成原生协议闭环，再开放入口。
