# v0.1.41：DSH 打开与安全重连

本版改进合并到 v0.1.42 发布；本记录保留发布前的本地验证证据，部署结果以 v0.1.42 的发布记录和线上版本为准。后续版本见 [体验优化计划](UX-OPTIMIZATION-PLAN-2026-10-24.md)。

## 用户行为

- 设备页“打开 DSH Web”进入独立等待页，不再打开没有解释的空白标签页。新窗口被拦时，原页提供相同等待入口，链接不包含一次性凭据。
- 等待页显示目标设备、可证明的等待阶段及失败原因；“核对状态”只读，“重新连接”显式请求打开/复用。取消等待返回设备不等于停止服务，页面中明确说明；迟到回包不再跳离当前页面。
- 返回设备时展开 DSH 区域，并把焦点放到实际可见的展开控件。停止服务前说明运行任务影响；只有电脑回执确认停止后才显示成功。
- 票据过期、浏览器授权过期、设备离线、转发失效和隧道不可用的顶层导航提供无脚本恢复页，引导返回 CodeGate 重新授权。API 与 WebSocket 仍保持失败状态码，不把错误伪装成成功 HTML。固定一小时授权期限不延长。

## 执行与安全

- Agent 检查 IPv4/IPv6 的固定本机 3080 端口；遇到外部监听只返回端口占用原因，不认证、接管或结束外部实例。
- 已有受管 DSH 必须通过带现有 Cookie 的本机健康检查才能复用。不使用启动 token 重新认证；地址变化或认证/健康失败要求人工核对，不自动重启。
- 每设备启动/停止操作共享一个有界回执；相同请求合并，相反操作互斥。HTTP 等待者离开后仍接收 Agent 回执；结果不明保留为需要核对，不把超时当作已停止。
- 新增只读 `GET /api/v1/devices/{id}/dsh-web/status`，区分离线、尚无确认转发、启动、停止、已有转发和结果未确认。“已有转发”不代表网页已加载或模型已完成。
- DSH 错误码只映射固定安全文案，不透传 CLI stderr、Cookie、启动 URL、命令行或任意 Agent 错误消息。继续保持票据一次使用、Cookie/Origin、设备和账号归属校验。
- Agent 新增 `dsh_web_lifecycle` 能力。新版 Server 的安全打开需要此能力；旧 Agent 显示明确升级要求，不发送可能按旧逻辑重启实例的请求。**部署需要同时升级 Server/Web 和 Agent**；升级受现有终端/任务/DSH 空闲约束，不强制更新正在工作的 Agent。只读状态与显式停止保持可用。
- 无数据库迁移。Server 重启不持久化转发认证秘密；失去状态后返回设备重新核对，禁止盲目结束旧实例。

## 设计心理学

入口以“打开、重新连接、核对状态、停止”表达目标；把配置、转发回执、页面加载和执行结果分开。失败保留恢复入口，停止需要明确选择和真实回执，返回后恢复焦点；通过能力门控和请求合并防止误重启与重复操作。手机使用现有克制视觉风格，不显示虚假进度。

## 验证证据

- 先复现失败：过期导航仅返回文字、Agent/Server 丢失 DSH 原因、旧入口打开空白页、错误类型回执被误认为停止成功、离线被误报撤销权限；对应回归修复后通过。
- Go Agent、Server、Protocol 全包测试通过；后续 Go 改动的 DSH 针对性测试及三个包 vet 通过。覆盖共享操作、取消 HTTP 等待后的回执、互斥、明确失败释放保留项、旧 Agent 门控、停止回执类型、其他设备授权保留、状态接口鉴权、过期页及现有 Cookie/Origin 回归。
- 前端 UX、会话恢复/切换、文件传输与图片粘贴回归、类型检查和生产构建通过。控制器覆盖重复调用、切换来源/离开后的旧响应、离线、停止中、失败后只读核对及非法跳转地址。
- 安装的真实 DSH `0.2.0-rc.2` 在独立 DSH_HOME、空目录及临时端口完成启动、token/Cookie 交换、健康复用、地址变化拒绝和原实例仍可访问检查。未使用用户 3080 实例或修改其配置，外部模型调用为 0。该检查可通过 `CODEGATE_DSH_SMOKE=<已安装的 dsh/lib/bin.js>` 启用 `TestDSHIsolatedLifecycleSmoke`。
- 独立模拟设备与生产前端构建完成 **13 项浏览器检查**：端口原因与重试、只读核对、320px 无横向溢出、键盘操作、真实等待文案、取消等待后的迟到回包、返回时展开与焦点、独立窗口交接、停止确认取消/接受与回执、无 JavaScript 运行错误。HTTP 409 为有意模拟的业务错误，不视为网络“零错误”。

## 验收限制

真实 DSH 检查验证本机生命周期函数，没有运行完整新版 Agent/Server 生产隧道，也没有恢复或执行用户的真实模型任务。浏览器使用模拟设备和受控请求，不代表线上已经验收；iOS/Android 实机软键盘、安全区、DSH 内部设置和聊天布局属于 v0.1.42。当前运行服务、用户 Agent 和已修复的 DSH 不因本次开发而替换或重启。
