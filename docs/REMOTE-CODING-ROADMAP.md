# 远程编程分期计划

每期独立 PR，必须通过真实 Git 仓库测试、Agent/Server 联调、桌面和手机浏览器验证及 GitHub CI 后合并。VERSION 随 Agent 运行代码一起递增。

| 版本 | 范围 | 验收 |
| --- | --- | --- |
| v0.1.7 | 会话 Git 面板：分支、改动文件、未暂存/已暂存差异、新文件预览 | 真实 Git 状态/差异/重命名、路径授权、设备归属、手机和深色模式 |
| v0.1.8 | 新会话可创建独立 Git worktree 和新分支 | 两个任务文件隔离、原仓库不受影响、创建失败回滚、目录越界拒绝 |
| v0.1.9 | 任务模板预填终端输入；明确确认后提交全部改动、推送当前分支 | 任务仅预填不自动执行、真实提交和本地 bare remote 推送、失败不伪报成功 |

现有断线接回和账号同步项目收藏继续复用。不会将终端安静判断为任务完成，也不会自动确认 CLI 的权限提示。

后续候选：结构化 CLI 任务状态与通知、网页预览代理、GitHub PR 集成、worktree 清理管理。它们分别需要 CLI 协议适配、端口转发授权或 GitHub 身份集成，单独安排后续版本。

## 使用体验改进（设计心理学检查）

依据可发现性、明确反馈、减少记忆负担、容错恢复与复杂信息分层，分三期交付：

| 版本 | 范围 | 必须通过的验证 |
| --- | --- | --- |
| v0.1.11 | 首页继续工作；项目内选择 CLI、目录、工作方式及模板；终端设备/工具/分支/目录；扫描状态；移除入口撤销；更新忙碌与退避反馈 | 真实会话启动/接回；独立工作区；模板不发送输入；扫描中不报空；离线/缓存禁用原因；320px/390px/桌面及深色模式 |
| v0.1.12 | 独立工作区列表与安全清理；展示改动、未保存在主工作区分支的提交和会话占用；从保留目录再次启动 | 真实 Git worktree；脏/忽略文件、独有提交、存活会话阻止清理；路径/所有权校验；清理不删除分支、不触碰原目录 |
| v0.1.13 | 真实提交与上游 ahead/behind 状态；受限 GitHub 比较/PR 链接；真实进程退出通知 | 本地 bare remote 验证；无上游和已变更 HEAD；不把进程退出等同任务完成；外部链接只接受可信 GitHub URL；通知需用户主动启用 |

每期独立 PR，本地真实 Agent/Server、浏览器和 GitHub CI 验证后合并。通用网页预览代理、CLI 结构化任务状态和 GitHub OAuth/API 写入仍为后续独立版本，不推断 CLI 输出静默为完成，也不自动发送任务模板。

### 独立工作区清理规则

从项目卡片或终端身份栏进入“管理独立工作区”。列表只包含 Git 登记且目录 UUID、`codegate/task-UUID` 分支都匹配的 CodeGate 工作区。忽略文件（如依赖缓存）也属于需要保留的本地数据，必须自行处理后才能清理。独有提交按当前主工作区 HEAD 计算，先合并到主工作区再清理；清理成功后仍保留 Git 分支。

清理前先停止其他编辑器和后台服务；Agent 会阻止自身会话创建与清理并发，并在执行前重读状态、检查 HEAD。外部程序不受 Agent 的互斥锁控制。Git 清理不使用 force，危险操作需明确确认。升级 Server 和 Agent 到 v0.1.12 后可用。

### 成果与通知的边界

Git 面板展示最近提交及基于本机远端引用的 ahead/behind，不自动 fetch，不把“工作区干净”解释为任务完成。GitHub 比较和 PR 查找入口只接受规范的 github.com 仓库 URL；含凭据、非 HTTPS/SSH、其他主机和不明确路径均不生成链接。创建 PR 仍在 GitHub 页面由用户完成。

Agent 上报真实会话进程退出，Server 验证会话设备/账号归属，向该账号在线网页发送事件。设置页可主动启用系统通知；只在网页处于后台且保持连接时弹出，通知不包含任务名称、终端内容和目录。页面关闭后的推送、CLI“等待输入/任务完成”结构化状态不在此版本范围内。事件只保存在本次网页连接中，登出即清空。
