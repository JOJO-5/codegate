# v0.1.42：DSH 手机布局兼容层

本记录描述 v0.1.42 的发布范围和发布前验证，包含 [v0.1.41 打开与重连改进](RELEASE-v0.1.41.md)。实际镜像、部署和 Agent 切换结果以 GitHub v0.1.42 发布记录及线上版本为准。[线上打开缓慢排查](DSH-INCIDENT-2026-10-24.md)单独记录，不将本地测试当成线上已修复。

## 用户行为与设计心理学

手机优先展示对话与输入，侧栏展开为抽屉，提供“返回对话”、Escape、Tab 焦点约束和关闭后焦点返回。设置页改为顶部可横向滚动的分类、全宽内容，保留模型、权限和高级选项。输入字号 16px，主要按钮至少 44px，修复折叠栏按钮裁切、横屏触摸尺寸和右侧面板重复偏移导致的底部越界。

布局采用现有深浅色主题，使用 VisualViewport 更新可视高度、安全区留白。仅将工作区按钮内精确的 `createMode` 文本替换为“选择工作区”，不读取或修改用户输入。原生文件与预览仍沿用 DSH 面板。顶部“使用原版 / 启用手机布局”即时切换，不刷新页面、不清空草稿，偏好保存在当前浏览器。

入口、返回与反馈文字明确，保持用户控制权；未经验证的版本保留原版布局并说明原因。布局兼容不代表模型配置、执行结果或真实手机验收已经通过。

## 兼容边界与回退

- CodeGate 代理注入自有外部 JS/CSS，不修改全局 npm 文件，不安装第三方插件，不发模型请求，不读取 Cookie、凭据或对话内容。
- 固定已验证 DSH `0.2.0-rc.2` 的三个前端资源名称及布局选择器；只有这些资源匹配才启用适配。20 秒内未出现约定布局节点时退回原版。未知构建仅显示可关闭提示。
- 仅处理成功的根 HTML，读取上限 2 MiB。压缩内容、上游 CSP、超大文档保持原始响应；API、资源和 WebSocket 不改写。更新 Content-Length、移除旧正文校验标记。原有账号、设备、Cookie、Origin 授权继续生效，自有资源同样需要授权。
- `CODEGATE_DSH_MOBILE_UI=false` 可由运维全局关闭；单个浏览器仍可使用顶部原版切换。`X-CodeGate-DSH-Mobile` 与只读状态接口 `mobile_ui` 记录适配兼容结果，不作为页面加载成功的回执。
- 适配范围为宽度不超过 700px，或宽度不超过 950px 且高度不超过 500px 的横屏。其他桌面视口保持原生布局。
- 无数据库迁移。仍需遵循 v0.1.41 的新版 Agent 能力门控；不能为更新而强制重启活跃 Agent/DSH。

## 验证与复查

- Go Agent、Server、Config、Protocol 全包测试及 vet 通过。覆盖版本钉住、关闭开关、非法配置、CSP、压缩、非 HTML、超大 HTML 原样读回与自有资源授权。
- 发布前额外运行 Windows `go test ./...`：所有业务包通过，`cmd/ttyprobe/TestInterruptAgainstCmd` 失败。该实验断言旧版 ConPTY 的错误行为；在未修改的 v0.1.40 提交归档中同样复现。保留该基线问题，不将其记作全量测试通过，也不为本次发布修改终端中断语义。
- Web UX 回归、类型检查、生产构建通过。
- 真实已安装 DSH、独立 DSH_HOME、临时端口，完成浏览器 27 项断言：320/360/390/430px、844px 横屏、主要触摸区域、字号、抽屉焦点/Tab/Escape、设置四个分类、草稿原版切换、缩短视口、深色主题、桌面工具条隐藏、右侧面板边界和未知版本回退；未发送模型消息。
- 可重复运行：设置 `CODEGATE_DSH_SMOKE` 指向安装的 `dsh/lib/bin.js`，执行 `node scripts/dsh-mobile-fixture.mjs`，将 `http://127.0.0.1:4190/_fixture/mode?value=adapted` 请求一次，再用 Playwright CLI 在该站点执行 `web/tests/dsh-mobile-browser.js`。该文件是 CLI 的 `run-code --filename` 脚本，不是 Node 单元测试。截图输出到 CLI 工作目录，应使用仓库外测试目录或 `output/playwright/`。
- fixture 将首次默认工作区也重定向到临时目录，过滤常见模型凭据环境变量；测试结束请求 `/_fixture/shutdown`，只结束其创建的进程树。不要按 DSH 进程名称批量停止。生产 3080 监听不参与测试。
