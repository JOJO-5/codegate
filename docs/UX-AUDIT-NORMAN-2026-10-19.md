# CodeGate 手机与桌面界面复审及本地改进

日期：2026-10-19。基线：v0.1.36，加上此前尚未发布的项目状态文案修正。本轮改进纳入 v0.1.37 打包；生产部署另行执行。用户图片不纳入版本。

## 审查结论

主要问题是任务层级不清、重复信息和操作竞争。设备页先出现两个后台面板和完整创建表单，已有会话要滚动很久才能看到；项目卡片把任务入口、路径、核对信息、管理动作同时展开。仅换颜色或增加装饰不能解决这种“功能拼在一起”的感觉。

本轮以“先继续工作，再创建任务，最后管理设备”为结构。视觉采用低饱和蓝灰、柔和浅底与深灰暗色、分级字号、统一圆角和留白；保留原生按钮、表单与现有终端风格，没有添加宣传区、闪光效果或新的产品概念。

设计心理学依据沿用 [AGENTS.md](../AGENTS.md) 与[前次审查](UX-AUDIT-NORMAN-2026-10-14.md)。键盘、状态、移动端和内容约束另参考 [Web Interface Guidelines](https://raw.githubusercontent.com/vercel-labs/web-interface-guidelines/main/command.md)，2026-10-19 获取。本轮区分代码检查、隔离浏览器验收和真实设备验收。

## 发现与处理

| 优先级 | 发现及证据 | 本地处理 | 心理学对应 |
|---|---|---|---|
| P1 | `web/src/views/DeviceDetailView.vue`：空预约/调度面板与创建表单在会话前。390px 截图首屏看不到已有工作 | 会话优先；桌面主区为会话/后台任务，侧区为启动/设备管理；手机顺序一致。顶部保留新建入口及会话、后台任务、工具锚点 | 按用户目标组织复杂性，减少寻找成本 |
| P1 | 同页：首次加载及失败可能显示“还没有会话”；`canOpen` 未要求当前连接与实时数据源 | 区分加载、失败、真正空数据；接回需设备在线、连接可用且为实时列表。缓存显示“状态待确认”，不误称设备离线 | 系统图像真实，约束与恢复 |
| P1 | `DevicesView.vue`、`SettingsView.vue`：设备/审计首次读取失败仍声称无数据 | 保留错误及刷新入口，未知不转成空结论 | 正确归因与可执行反馈 |
| P1 | `FilesView.vue`：320px 浏览器复现原生文件选择框撑至页面宽 336px | 限定上传控件宽度，同时补齐可访问名称 | 手机可操作，约束内容溢出 |
| P2 | `TaskLaunch.vue`：主 Agent 模式藏在默认 CLI 下拉选择中 | 两个有说明文字的原生单选入口，键盘方向键可切换；费用和范围说明继续保留 | 可发现、可理解，不依赖用户记忆 |
| P2 | `ProjectsView.vue`：打开新建任务后焦点仍留在远处触发器；滚动位置可能被固定顶栏遮住 | 打开后聚焦标题并预留顶栏距离；取消后回到触发按钮；不强制平滑滚动 | 操作映射、焦点与错误恢复 |
| P2 | 项目页：路径重复套框，多个主色按钮及四个管理动作同时竞争 | 路径作为次要信息；最近工作在桌面紧凑分栏，手机纵向；管理和仓库发现逐步展开 | 降低认知负担，行为层可预测 |
| P2 | `styles.css`：`.card + .card` 外边距导致同一网格的项目卡片上下错位；省略 type 的文本框未获得统一样式 | 网格卡片消除叠加外边距；统一默认文本输入、标题和路径换行 | 视觉一致性与工艺细节 |
| P2 | 顶栏导航、焦点和小屏控件密度不一致；设备详情缺少所属栏目选中提示 | 增加跳过导航、设备栏目提示、明显焦点、手机 44px 主要点击区和 16px 输入字体；尊重减少动效设置 | 键盘、触摸和读屏路径一致 |
| P2 | 深色链接与按钮复用同一个强调色，难以同时满足可读性 | 链接和填充按钮分开用色，调低饱和度；文字/背景关键组合计算对比度达到 4.5:1 以上 | 本能层安静，行为层可辨识 |

“逐步展开”的边界：项目设置、仓库浏览、DSH 设置、新建表单可收起；后台任务的读取错误、运行/停止状态与取消入口继续保留在任务面板中，不因空列表或读取失败隐藏整个面板。DSH 展开状态由用户控制，操作结束不自动收起其结果或恢复链接。

## 操作路径与恢复

- 继续工作：项目的最近工作，或设备会话列表。存活会话接回；结束会话保留恢复原对话入口；缓存和断线状态说明不能接回的原因。
- 新建任务：项目卡片 → 新建任务 → 明确选择 CLI 对话或主 Agent 自主调度。打开时标题可见且获得焦点；取消回到原按钮。未新增 CLI 或模型能力。
- 设备启动：顶部新建对话 → 展开原表单并聚焦。收起表单不会卸载它，因此当前字段保留；已有 `?create=session` 链接仍会打开表单。
- 后台处理：设备的后台任务锚点到达预约与调度面板；原有停止确认、历史删除/撤销、输出与原生身份规则不变。
- 管理与恢复：项目设置中改名/移除，仍保留撤销；设备设置和更新维持独立入口。读取失败可刷新，不以新建任务代替恢复未知任务。

## 验证记录

自动化：`npm --prefix web run test:ux`、`test:conversations`、`test:transfer`、Vue 类型检查及生产构建通过。新增 `web/tests/layout-navigation.mjs`，加入现有 UX 测试入口；补充上传控件可访问名称检查。测试覆盖渐进展开、两种执行方式、加载/失败/空状态、实时/缓存/断线接回条件和准确禁用文案。

隔离浏览器使用真实构建、HTTP/WebSocket 测试服务和虚构设备/会话数据。操作不连接生产执行设备，不发起真实模型请求：

- 浅/深两主题 × 320、390、768、1440px × 项目、设备列表、设备详情、设置、独立工作区、文件、Git 共 56 组；无页面横向溢出、主要按钮/标题越界和前端 pageerror。文件/Git 等依赖会话操作的页面在该数据服务中覆盖受控不可用路径，不能当作成功读取真实文件或 diff 的验收。
- 项目设置和仓库用 Enter 展开，模式用方向键选择，主 Agent 表单可填写；测试调度提交后取消，界面等 Agent 停止回执。
- 设备会话先于后台任务；新建入口展开并聚焦；输入为 16px；跳过导航能聚焦主要内容。
- 首次会话读取失败不显示“还没有”；后台调度失败保留错误；恢复服务并刷新后，实时接回按钮重新可用。
- 补充新建任务标题不被固定顶栏遮挡、取消后焦点回原按钮的实际浏览器检查。

颜色抽查：浅色主按钮白字约 7.13:1；深色主按钮白字约 5.61:1，悬浮约 4.95:1；深色链接与卡片约 7.81:1。其他次要文字与提示也调整到关键背景组合不低于 4.5:1。禁用控件低透明度表示不可用，不能靠禁用颜色替代原因文字。此为 token 组合检查，非整站可访问性认证。

## 设计自查与后续边界

| 维度 | 本轮结论 |
|---|---|
| 方向一致性 | 工作台围绕继续、创建、管理建立层级，状态与执行概念分离 |
| 视觉层级 | 正文与次要路径区分，主操作克制，桌面并列、手机纵向；任务错误不伪装为空 |
| 工艺 | 修复网格错位、原生控件溢出、输入样式不一致、焦点和顶栏遮挡 |
| 功能 | 保留原有 API/执行能力和控制权，通过展开管理降低信息密度 |
| 识别性 | 保留 CodeGate 字标、字体和终端语境；用结构与细节建立完整感，不增加装饰噪声 |

后续仍应处理跨设备的待处理任务汇总、长列表筛选/分页和任务与项目产物的统一回访入口，先确定真实状态来源再扩展，避免再次把新面板堆到首屏。统一 CLI 调度仍按[独立路线图](CLI-ORCHESTRATION-ROADMAP.md)推进，不属于这次视觉改进。

未验收：真实 iOS/Android 的软键盘、刘海安全区、系统缩放与触摸手感；人工读屏；长时间终端输出及大量任务性能；生产模型完整任务链路与本次页面在生产环境的接受度。终端执行、权限、数据库和 Agent 更新逻辑本轮未改，不能由 Web 构建通过推断其整体没有 bug。文件、Git 和工作区完整成功操作仍需真实设备回归。

打包前复查补充：修复项目页会话读取失败仍显示“此目录还没有会话”、最近会话读取失败显示为空，以及保存项目加载失败显示尚未保存的问题。新增实际模板渲染回归测试，先确认失败再修复；成功空列表仍保留原提示，失败提供刷新恢复入口。遵循真实反馈原则，避免用户因误以为数据丢失而重复创建。
