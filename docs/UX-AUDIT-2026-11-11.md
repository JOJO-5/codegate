# v0.1.48 使用体验复查

2026-11-11。核对仓库 HEAD `c333557`、线上 Server 和本机在线 Agent 均为 v0.1.48。范围是项目工作空间、新建终端、任务中心及手机信息排布；本轮仅审查，未修改产品代码、用户数据或发布版本。

采用仓库设计心理学准则，并参照 [Web Interface Guidelines](https://raw.githubusercontent.com/vercel-labs/web-interface-guidelines/main/command.md) 的异步反馈、内容溢出、状态一致性与可恢复要求。以下按使用影响排序，不进行整体视觉重设计。

## P1：新建终端缺少结果不明后的防重和核对

`web/src/components/TaskLaunch.vue:44` / `web/src/stores/sessions.ts:155`：创建出错后只展示错误并恢复提交按钮；没有沿用原生对话恢复的待确认意图、结果核对或创建幂等身份。

隔离浏览器模拟请求已经创建终端但回执丢失：第一次派发计数为 1，界面仍允许点击“启动任务”；再次点击计数变为 2，未出现结果核对入口。关闭重开启动面板后，任务名称也丢失。这是客户端恢复路径与防重缺口，不是已确认的线上重复事故。

建议统一创建请求身份、持久化接收/执行回执，超时与断线先进入待确认，再核对真实终端；派发未知时不得换新身份重放。失败保留目录、名称、工作方式与待确认意图，但完全权限不保存为默认。

验收：普通终端、独立工作区、回执丢失、关闭重开、刷新、账号切换和旧回包；同一创建意图只产生一个真实会话/工作区。

## P1：项目页可能显示过时的设备在线状态

`web/src/views/ProjectView.vue:37` / `web/src/stores/devices.ts:41`：项目页调用不强制刷新的 devices.load，设备首次加载后直接复用缓存；15 秒轮询只刷新会话，不更新设备在线状态。

同一页面内将模拟 Agent 从在线切为离线，再手动刷新记录：设备 API 已返回 offline，页头仍显示“设备在线”，“开始工作”仍启用；再次刷新也一样。全页刷新会重新获取状态，本次已区分这两条路径。Server 权限门控仍存在，这不是服务端允许离线执行。

建议为设备状态建立明确的实时/最后确认/未知模型，使用上下线通知或有时效的按设备刷新；刷新入口需真正核对在线状态。重连中、缓存和离线分别表述，避免让用户在错误入口反复尝试。

验收：保持页面不刷新时上下线、跨项目导航、浏览器断线恢复、手动刷新、旧响应晚到；不能由陈旧在线值授权新操作。

## P2：后台刷新会使主要操作消失

`web/src/views/ProjectView.vue:40` / `web/src/views/ProjectView.vue:82` / `web/src/stores/sessions.ts:81`：每 15 秒刷新时重新进入全局 loading，并先替换为缓存来源；所有正在运行会话的“接回终端”暂时变成“状态待确认，请刷新”。

模拟实时列表响应 2.2 秒时，接回链接从 4 个变为 0 个，再恢复。自动刷新却要求用户刷新，容易被理解为故障，也会改变正在点击的操作目标。

建议区分首次加载、后台更新与真正失联。后台更新保留列表和稳定操作位置，显示最后确认时间及轻量更新状态；过期、离线或失败后的门控另行处理，不能简单把旧状态永远当成在线。

验收：后台刷新、慢网、失败后恢复、多设备同时加载和键盘焦点；操作不闪跳，状态文案与实际阶段一致。

## P2：手机会话行被完整程序路径占满

`web/src/views/ProjectView.vue:81` / `web/src/styles.css:1031`：会话行直接显示完整 command，文字列与右侧状态共用 flex。390px 模拟真实长度的 Codex 安装路径时，状态区域仅约 34px，中文被拆成竖列；虽无横向溢出，仍明显影响阅读。

建议主行只显示工具名和会话状态，完整启动路径收纳到详情。窄屏状态/操作允许独立换行并保持可读宽度，沿用现有配色与按钮层级。

验收：320/390/430px、长名称、Windows 路径、更新中/离线/运行/已结束状态，以及键盘和读屏顺序。

## P2：任务中心尚未承接完整的历史管理

`web/src/views/TasksView.vue:66` / `web/src/views/TasksView.vue:70`：历史行没有直接清理入口，需要展开“查看过程与结果”，再跳旧设备页“管理续跑历史与撤销删除”。隔离浏览器确认该跳转存在，因此不应表述成后端没有删除能力。

建议任务中心直接管理已结束记录，提供筛选、批量选择和可撤销移除，明确区分隐藏入口、删除记录与取消执行；进行中或停止未确认的任务不能当成普通历史清理。保持来源、取消回执和产物证据可核对。

验收：已完成/失败/已取消记录、停止未确认、批量移除部分失败、撤销、刷新和旧回包；历史清理不会影响正在执行的任务。

## 建议次序和边界

第一批处理创建防重、设备状态同步和稳定后台刷新；第二批整理手机会话行与历史管理。原生 Chat 继续按已有协议方案独立推进，当前入口可靠性不应依靠新增功能掩盖。

已有重连退避修复已生效：当前日志中认证成功后的下一次故障从 attempt=1、约 0.5～1.2 秒起重试。公网仍出现握手/读超时，后续如优化网络应分别测浏览器到 Server、Server 到 Agent 和终端回显，不用更换 UI 代替网络定位。

浏览器使用本地构建的真实 Vue 页面与模拟 HTTP/WebSocket，未连接或启动真实终端、未发模型请求；本轮没有实机触摸/软键盘、真实模型、全项目安全或性能验收。隔离脚本与截图留在本机 release-tools，未加入产品代码。

## v0.1.49 本地实施与验收

本地实现以上五项，尚未提交、打标签或部署。本节记录实施结果，前文保留 v0.1.48 的审查证据。

- 新建终端：项目入口保存标签页与账号隔离的草稿和启动标识；旧设备页的新建入口也使用相同标识和核对界面。Server 在转发前以 SQLite 唯一约束登记启动意图，同一标识最多转发一次，普通终端与独立 Git 工作区共用此边界。迟到回执不依赖浏览器连接或内存 pending 表，确认失败与结果不明分别处理。参数不匹配的标识不能重用。没有登记过的意图，须显式确认原参数后才可按同一标识重新提交。
- 权限：普通草稿不保存 CLI 权限模式；待核对记录只保留该次请求的原始权限供展示和核对，不会自动执行。重新提交需要再次明确确认，后续新建仍默认继承 CLI 本机设置。
- 设备状态：缓存具有时效，手动刷新、页面可见与 WS 恢复会重新核对；失败、浏览器断线或过期进入“状态待确认”，不能依靠旧 online 标志启动。迟到的旧账号数据、旧设备列表和旧会话列表不能覆盖新观察或进程退出事件。
- 后台刷新：项目使用按设备的刷新状态与最近确认时间，刷新过程中保留已确认接回入口和键盘焦点；核对失败、断线或确认过期才降为缓存。首次加载不再短暂显示空数据。
- 手机会话行：优先展示 CLI 名称与进程状态，完整命令按需展开。主操作保持可读宽度，离线/待核对原因独立占行，沿用原有配色与按钮层级。
- 任务历史：已结束续跑和已停止/已交付调度提供直接移除、按当前页选择、批量确认与撤销；移除只改变列表可见性，保留原始任务、幂等标识、代码、对话与证据。运行、停止未确认、派发不明记录不能移除。部分失败保留未确认记录，撤销身份在本标签页刷新后仍可恢复；确认、保留与撤销都提供焦点落点。移除或恢复记录不代表人工验收。

落实设计心理学：把“启动待核对”的原因与下一步放在面板首屏，把原参数放到按需展开；用真实回执约束成功与取消，维持主要操作位置，区分移除记录、停止执行和人工验收。

验证：

- 新增测试先复现旧行为，再完成修复。存储测试覆盖竞争登记、SQLite 关闭重开、首次回执不可被迟到响应覆盖；Server HTTP/WS 测试覆盖失去客户端、迟到回执、参数冲突、跨账号隔离，以及调度历史保护、保留证据与撤销。
- `npm run test:ux`、`test:conversations`、`test:transfer`、类型检查与生产构建通过。前端测试覆盖草稿、完全权限不成为默认、明确重新提交保留原标识、重新提交失败保留更早的不明意图、断线/账号切换及旧响应、批量部分失败与撤销。
- 隔离浏览器使用真实构建、模拟 HTTP/WS：320/390/430/1280px 无横向溢出；2.2 秒刷新中四个接回入口保持四个，焦点保留；上下线、状态读取失败与恢复；新建未知回执只派发一次，关闭面板/刷新后核对并进入原会话；旧设备页独立工作区创建也通过同一路径；任务批量部分失败、刷新、撤销、主 Agent 交付状态保留通过。页面运行时异常为零。截图已人工查看，位于本机 `release-tools/ux-optimize-1111-*.png`。
- `go test ./...` 中产品包全部通过；既有 `cmd/ttyprobe/TestInterruptAgainstCmd` 失败，单独重跑同样失败。该诊断断言 2026-09-28 的错误行为（写入 0x03 后 shell 不再接受输入），本机现观察到 shell 仍可接受输入；其代码及所依赖的 terminal/processutil 未在本次修改。没有为了通过检查而更改该历史诊断。

边界：如果意图已经派发、Agent 在返回回执前退出或回执永久丢失，会继续标记待核对，不会自动重放。标签页存储用于面板关闭与刷新恢复，不承诺关闭标签页后保存草稿。尚未进行本轮线上、真实模型、实体手机触摸/软键盘或读屏软件验收；这些不能由隔离浏览器和构建通过替代。
