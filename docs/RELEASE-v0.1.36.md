# v0.1.36 发布前复审

2026-10-18。范围：主 Agent 本机串行调度、OpenCode V2 适配、续跑历史整理与执行观察、连接恢复和 Codex 环境错误处理。

## 设计心理学结论

- 概念模型：主 Agent 由用户明确选择，不自动选用可能产生费用的 Codex；工作模型默认限免费，两者费用分开说明。原终端、后台执行、调度步骤、进程退出与待用户验收分别表达。
- 映射与证据：提交前展示设备、项目目录、Git 隔离方式、主模型和费用策略。复审补齐主脑及工作模型名称的执行快照，旧目录无法查询时也能知道当时选了谁；步骤区分执行中、失败、已阻止与需要核对。
- 可发现与认知负担：主界面选择主脑和目标，高级运行限制逐步展示；缺少模型时说明检查 CLI 安装、授权和 Agent 更新的路径。预约按进行中、需要处理、历史分类。
- 真实反馈与恢复：运行任务展示实际活动、最近同步与模型文字；离线保留快照，过期数据明确标记；不显示虚构进度。派发不明沿用提交标识核对，不重发提示词；凭据失效会暂停派发。
- 控制与防错：停止等待 Agent 回执，历史删除持久化并可撤销，不删除项目或原生对话。运行中、停止未确认和需要处理的记录不能直接删除。工作区使用期间禁止清理。
- 情感体验：沿用现有视觉风格，减少历史噪声；通过撤销、可追溯结果和明确的人工验收边界保留用户控制权。

参考 [Web Interface Guidelines](https://raw.githubusercontent.com/vercel-labs/web-interface-guidelines/main/command.md)。本轮没有新增设计阻塞项；以下验证边界保留披露。

## 验证证据与限制

- 功能回归涵盖账号归属、持久化、幂等、取消竞态、断线恢复、旧响应过滤、免费策略、工作区隔离与交付门控；Web 测试覆盖真实 HTTP/WebSocket 重连，以及草稿、错误状态、续跑控制和主脑提交恢复。
- 隔离浏览器页面已验证删除、批量整理、键盘撤销和焦点恢复、刷新保持、只读活动、停止确认及读取失败保留数据；390px 窄屏无横向溢出。读屏器人工验收尚未执行。
- 本机免费 Big Pickle 模型的真实调用、运行中取消及相邻会话隔离通过。免费主脑指挥免费工作模型经4次决策生成实际代码、通过 Node 测试与 Git 检查，原目录不变，测试会话费用全部为零。
- Codex 0.163.0 的真实 Windows 沙箱探针与原生守护进程读取通过；没有把 Codex 主脑到工作模型的完整付费/订阅模型调用当作已验收。
- 全仓 Go 测试中的 Windows `cmd/ttyprobe/TestInterruptAgainstCmd` 在当前代码及独立的原始 v0.1.35 提交上均失败：该诊断断言旧环境中 shell 会失去响应，本机观察到仍可接受命令。保留原测试，不将此既有环境差异写成通过；产品相关测试及 CI 分别记录。
- 跨平台复审发现并修复 OpenCode 路径别名的误判：同时解析预期目录和原生目录后再比较，覆盖 macOS `/var` 与 `/private/var` 的等价路径；仍拒绝其他实际目录，不降低授权范围约束。
- 历史读取仍有200条上限，达到上限会提示；活动仅保留有界的最近快照，不是完整日志回放。多机器调度不在本版范围。

## 部署边界

Server 使用不可变提交 SHA 镜像。迁移0006新增工作流表，部署前需备份停止后的完整 SQLite 数据及旧镜像，核对迁移和业务计数。目标电脑更新到新 Agent 后才能使用调度与实时活动；活动会话期间只暂存更新，不强制结束用户的 Agent 或终端。
