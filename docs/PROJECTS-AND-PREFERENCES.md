# 项目、偏好与手机剪贴板

在设备页选择已授权的 CLI 和工作目录，点击“保存为项目”。项目会出现在导航栏的“项目”页，保存到当前账号的 Server 数据库。

- “新建独立会话”启动新的 CLI 进程，不传恢复旧对话的参数。
- “接回已有会话”列出相同工作目录下的会话，由用户选择；只有设备在线且进程存活时才能接回。
- 移除项目只删除快捷入口，不删除文件或结束会话。
- 项目、会话置顶和终端字号按账号同步。页面重新打开、点击刷新或窗口重新获得焦点时读取最新偏好。
- 旧版本机置顶和启动组合可在设备页点击“导入到当前账号”；不会自动把本机数据归入某个账号。

终端工具栏提供“复制选中”和“粘贴”。“更多按键”中可复制当前可见画面和调整字号。粘贴先显示可编辑预览，确认后经终端的粘贴入口发送，不额外添加回车；已有换行仍可能让 Shell 执行命令。浏览器不允许剪贴板访问时，页面提供手动复制或粘贴输入框。

Server 启动时应用 `0003_user_preferences.sql` 迁移。偏好接口需要登录，只能保存当前账号拥有的设备项目和会话置顶；它不替代 Agent 对命令和工作目录的授权校验。
