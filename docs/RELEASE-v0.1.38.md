# v0.1.38

终端与输入框支持 Ctrl+V / ⌘V 粘贴图片，附件区新增“粘贴图片”按钮。图片先进入本地待上传预览，保留文字草稿，由用户确认上传并发送。权限拒绝时提供快捷键和选择文件的恢复入口，关闭或离开会话后不再接收迟到读取结果。

修复高延迟网络上上传逐块等待、块大小不断缩小的问题。附件与工作区文件上传采用每块 32 KiB、最多 4 块在途的有界流水传输，最终块等待此前全部确认；错误、取消和迟到回执不会驱动继续发送。最终落盘确认前进度不再提前显示 100%。

设计心理学：明确区分图片已添加、已上传及已发送；预览与上传都保留用户确认，错误有恢复入口，完成状态以真实回执为准。

验证：前端回归、类型检查与生产构建通过。隔离 Chrome 中完成系统剪贴板粘贴、权限恢复、上传失败重试、文字保留与窄屏检查。虚拟 800 ms 往返条件下，1 MiB 上传由 100 秒降为 7.2 秒；隔离真实 WebSocket 每块应答延后 200 ms 时，桌面/390px 上传约 2.4 秒，SHA-256 一致且终端输入可用。这些数据不代表用户实际网络测速。

Server / Agent 协议及数据库迁移均无变化。真实 Mac、Safari/Firefox、手机系统剪贴板与软键盘，以及模型图片理解仍未验收。详见[图片粘贴说明](CLIPBOARD-IMAGES.md)与[上传性能记录](UPLOAD-PERFORMANCE.md)。
