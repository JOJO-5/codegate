# v0.1.45：手机终端操作、粘贴恢复与 Ctrl+C 防误退

本次改善浏览器终端的手机操作，保留既有界面风格。没有数据库迁移、Server 接口或 Agent 运行逻辑变更；普通终端中断沿用已有协议。以下记录实现和验证范围，线上部署及 Agent 实际版本以发布记录为准。

## 用户可见变化

- 手机常用按键新增直接可点的 **Shift+←**，与物理键盘发送相同序列，不附加回车。Shift+Tab、左右移动、空格和任务模板收纳在“更多操作”，模板仍只预填。
- 底部工具区限制高度并独立滚动，展开工具后保留终端输出；320px 下六个主按键保持一排和 44px 触摸高度。点快捷键不意外唤起软键盘，回到输入框可正常输入。
- 按实际编程 CLI 命令、已知 shim 和原生绑定识别 Codex、Claude Code、OpenCode、DSH，禁用 Ctrl+C 并显示“防误退”。普通 Shell 启用中断，会话改名不影响规则。物理键、输入框发送和粘贴不能绕过保护；断线、只读、未接回和已结束时不发送，受阻时保留文字。
- 剪贴板读取区分等待、空数据和权限失败，支持手动粘贴与重新读取。迟到结果不覆盖编辑内容，取消和离开页面后忽略旧结果；重新打开保留未粘贴预览，断线恢复不自动发送。
- 手机会话切换面板跟随实际工作区，补齐关闭按钮、外侧点击关闭和焦点恢复。选择当前会话也会收起面板；桌面继续常驻显示。
- 终端查找框和前后查找按钮补齐读屏名称，保留键盘聚焦和 Escape 关闭。

通过明确按键和关闭入口、低频功能渐进展示、真实等待反馈及保留输入的恢复路径落实设计心理学准则。中断当前命令与关闭整个会话保持独立。

## 验证与边界

- Web 会话、上传/粘贴及 UX 回归，类型检查与生产构建；先用失败测试证明迟到剪贴板覆盖、输入框绕过保护和未附着发送等问题，再修复。
- 隔离浏览器对真实 Vue、HTTP/WebSocket 路径完成 92 项检查，覆盖八种视口、深浅主题、按键字节、草稿刷新、只读/断线恢复、不自动重放、剪贴板失败/取消和焦点。模拟设备与剪贴板，不调用真实 Agent/模型，不读取真实剪贴板。
- 本机真实 ConPTY 回归验证 cmd、Windows PowerShell 5.1 的持续 ping，以及 PowerShell Start-Sleep 中断后仍能继续执行命令。后端无需调整；历史 Windows Shell 禁用结论已标注修订。
- cmd 和可用的 PowerShell 7 参与 Windows 自动 Shell 生命周期回归；旧 Windows PowerShell 5.1 为显式本机验收项，本机通过，Hosted CI 的输入环境差异尚未解决，不将其宣称为已验收。不修改产品后端或用户环境。
- 未验收手机实机软键盘、Safari、安全区和读屏全流程；本机未安装 pwsh 7，其他 Windows 版本和真实编程模型的取消语义未据此宣称通过。
