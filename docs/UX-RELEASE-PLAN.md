**v0.1.32 行为约定**

- 未发送终端文字按账号、会话隔离，新建文件草稿按账号、会话、目录隔离。
- 草稿保存在当前标签页的 sessionStorage，不发送给服务器；切换页面、关闭文件面板及刷新后可恢复。退出账号或切换账号清除旧账号草稿。
- 浏览器拒绝或无法写入存储时，保留内存草稿并显示刷新前复制的提示。
- 发送或成功保存清除相应草稿；新文件编辑器可收起保留，丢弃需要确认。
- 请求失败不被解释为空列表；缓存结果保留并说明来源，成功重试清除读取错误。
- 项目页与设备页使用相同的恢复资格判断和原对话恢复组件；普通 Shell 不被当作可恢复编程对话。

**各版验收**

v0.1.32：长提示词跨会话、Git 页面及刷新后恢复；文件草稿跨面板和目录恢复；退出登录无旧账号草稿；首次请求失败有错误与重试；真实空列表无错误；项目页可从已结束编程记录恢复原对话。自动检查通过与真实浏览器操作分别记录。

v0.1.33：用户能明确判断是否共享文件；添加项目与新会话进入实际创建流程；会话操作可发现并保留结束进程确认；模态框 Tab/Escape/返回焦点正确；设备离线和 Agent 超时有对应下一步；工具选择作用范围一致。

v0.1.34：升级等待原因和下一次检查时间真实可解释；手动安排可取消；成功上线有完成反馈；摘要只显示可验证的执行、文件和交付状态，不将进程退出或 CLI 返回等同于任务完成。

每版保持现有配色、卡片和终端视觉语言；提交、镜像构建、部署及线上验收按版本单独进行。

**v0.1.32 本地验证记录（2026-10-14）**

- Vue 类型检查、生产构建、UX 回归、会话分组/恢复资格及文件传输回归通过。UX 回归先验证旧实现的失败，再验证修复后的错误、空状态与草稿存储行为。
- 使用生产前端构建、本地 HTTP/WebSocket 模拟服务和独立测试账号进行浏览器检查：终端往返 Git 页面及刷新后恢复；文件名称和内容刷新后恢复；进入子目录再返回恢复根目录草稿；收起编辑器再展开恢复；登出清除草稿存储。
- 浏览器检查使用模拟设备，没有操作生产 Agent 或正在使用的会话。真实 CLI 的原对话恢复、移动端实机及线上发布验收仍待执行。
- 创建文件期间禁止切换目录，避免保存成功后清除其他目录的草稿。

**v0.1.33 / v0.1.34 本地验证记录（2026-10-14）**

- 两个里程碑在当前工作区完成，最终 VERSION 为 v0.1.34；用户已授权提交与上线，发布结果按实际镜像和服务验收记录。
- 添加项目直接打开已有目录入口表单；新对话进入并聚焦设备创建表单，带入原工作目录。原目录共享文件与 Git 工作区隔离的区别在选择处说明。
- 工具选择按设备与仓库路径隔离。恢复、续跑和添加项目使用同一原生模态框，支持焦点限制、Escape、返回原按钮；请求进行时防止关闭。
- 终端操作按浏览与复制、显示与查找、会话控制分组，保留结束进程确认。离线和 Agent 超时保留对应业务提示。
- Agent 心跳报告终端、操作和 Web 阻塞项，以及下一次自动检查时间。等待状态不会修改最近检查时间；手动检查后重排下一次自动检查。
- 取消操作仅撤销手动重启，不删除更新包或关闭自动空闲升级。切换开始后拒绝取消；旧 Agent 不显示取消按钮，详细等待项缺失时明确显示未知。
- 用 Agent 实例启动时间及版本变化识别重新上线；完成检查与失败更新请求提示。时间比较使用 Agent 前后检查时间，不依赖浏览器与设备时钟同步。
- 工作摘要按需读取进程、Git 与后台任务，保留失败时的缓存并提示过期风险，提供原对话、文件、Git 的人工核对入口；没有推断任务完成、CI 或部署成功。
- Vue 类型检查、生产构建、UX/草稿/错误提示、会话分组和传输回归通过；Agent、Server、Protocol、Session、Updatefile 包测试通过。新增升级取消、旧版兼容、检查时间和自动检查重排测试通过。
- 独立本地模拟账号的浏览器检查通过：仓库选择隔离、创建表单定位、模态框 Tab/Shift+Tab/Escape/焦点返回、取消后按钮消失并明确保留自动升级、项目事实摘要。手机尺寸检查确认弹窗宽度适配。
- 尚待真实 CLI、真实 Agent 升级重连及移动端实机验收；未干预正在使用的 Agent 或生产会话。

**线上续跑反馈：v0.1.35 修复**

- v0.1.34 已部署到服务端，提交 d1c8cee，镜像 CI 成功。数据库备份与切换前后计数一致；公网版本、前端资源和 Agent 下载接口通过。
- 线上三条实时额度任务均为 needs_review，原因是“原终端与 Codex 原生对话身份不一致”，没有开始续跑。不是用户选错模式。
- 生产 Agent 的终端 UserID 为 uuid.Nil，授权由 Server 执行；实时续跑错误地要求它等于服务端用户 ID。修复后允许这种生产终端，同时继续拒绝已明确绑定其他用户的终端，并保留原生身份、命令与工作目录检查。
- needs_review 可取消安排，保留失败原因和核对要求；已结束记录可在当前标签页收起、显示和刷新恢复。没有删除历史，也不会自动重新派发旧失败任务。
- 取消直接显示服务端确认结果，并使旧的列表读取失效，避免稍后的旧响应把界面恢复成未取消。
- 状态说明区分“下次状态核对”与“下次派发检查”，明确需要确认时不会自动重试。
- 新增生产终端、错误用户、需要确认取消、取消与旧列表竞态、收起记录生命周期回归；UX 回归纳入 Web CI。
- 本机 Codex 守护进程连接探针另有失败；真实实时续跑还需要新版 Agent 和可连接、已加载原对话的本机 Codex 守护进程。保留当前会话，不强制重启 Agent。
