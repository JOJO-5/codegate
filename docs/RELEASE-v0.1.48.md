# v0.1.48：压缩历史与 Windows 原生对话恢复修复

点击“恢复原对话”时，原历史仍在却提示“没有找到原生对话”：CodeGate 漏掉 `.jsonl.zst` 压缩历史，且 Windows 扩展路径与普通目录的字符串比较可能不相等。现在可识别该压缩格式，并核对 Windows 文件系统身份以匹配同一项目目录。

## 范围

- 需要更新本机 Agent；没有数据库迁移或新增接口。
- 沿用原生身份绑定、白名单、解压与扫描限制、缺失历史拒绝、重复恢复复用及回执不明后的核对流程。
- 不自动发送提示词、不更换模型。保持“恢复原对话”的目标与实际历史对应，避免将可恢复的压缩历史误报为删除。

## 发布前验证

- 修复前复现两项失败，修复后针对性回归及 Agent 全包测试通过；Agent vet、Server/Agent 构建、版本检查通过。
- 本机两条相关历史只读查找唯一命中，不输出对话正文。
- 真实 Codex CLI 0.164.0 使用隔离目录完成压缩历史冷恢复、关闭后恢复、缺失历史拒绝与重复恢复复用；模型调用为 0。

真实用户点击后的线上恢复和手机操作仍需更新 Agent 后验收。排查证据见 [故障记录](FIX-COMPRESSED-CONVERSATION-RECOVERY-2026-11-10.md)。
