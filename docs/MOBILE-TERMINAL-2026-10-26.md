# 手机终端输入与布局优化

v0.1.45 的实现与验收记录。目标是在手机上处理 CLI 的询问、切换选项和确认，同时保留足够的终端输出及未发送文字；实际部署状态以发布记录为准。

常用按键保留在输入框下方，按用户确认新增可直接点的 **Shift+←（Shift 加左方向键）**，不附加回车。更多操作中提供 Shift+Tab、左右方向键、空格，并收纳任务模板；模板继续只预填。断线、只读、未接回和已结束会话禁止发送按键，恢复连接不会重放按键，草稿保留。

底部操作区限制在可用高度的 55% 内，超出部分自身滚动，避免展开工具后挤没终端。320px 下六个主按键保持一排及 44px 触摸高度。保留原有配色、按钮语言和主要操作位置，通过明确按键名称、低频功能渐进展示、真实连接约束来降低认知负担和误触。

## 补充审查与修复

- 剪贴板读取曾会覆盖等待期间手动输入的文字。先用延迟回包测试复现，再加入请求代次保护；编辑、取消、离开页面后忽略旧结果，重新打开保留尚未粘贴的预览。提供读取中、空剪贴板和权限失败的不同反馈，以及手动输入和重新读取入口。取消/确认后恢复入口焦点，断线保留预览且重连不自动粘贴。
- 手机会话切换面板原先固定在页面 `top: 45px; bottom: 76px`，390×844 下实际面板为 y=45–768、工作区为 y=72–693，覆盖会话信息与输入区。改为按真实工作区定位，补上明确的关闭按钮、外侧点击关闭及选择当前会话后收起；保留 Esc 和焦点恢复。桌面继续常驻显示。
- 终端查找框和上/下查找按钮补齐可访问名称，保留打开聚焦和 Esc 关闭。
- 输入框发送原先绕过按键的连接/附着检查和编程 TUI Ctrl+C 保护。用回归测试复现后统一到受保护的发送路径，被拦截时不清空文字；粘贴预览含 Ctrl+C 控制字符时也保留内容并提示移除。

这些修改落实明确能指、及时反馈、防错和可恢复操作；审查参考 [Web Interface Guidelines](https://raw.githubusercontent.com/vercel-labs/web-interface-guidelines/main/command.md)。

## 验证与边界

- 先观察按键派发测试失败，再实现保护路径；会话恢复和切换回归、Web UX、类型检查与生产构建通过。
- 隔离浏览器使用真实 SessionView、HTTP 和 WebSocket，记录发出的键值：Shift+← 为 `ESC [ 1 ; 2 D`，与 xterm 处理键盘 Shift+ArrowLeft 发出的字节一致；Shift+Tab 为 `ESC [ Z`，空格为单字节空格，均无附加回车。57 项检查通过，包括草稿、只读与断线门控、重连不重放、刷新恢复、触摸键盘意图、深色按键对比度和 320/360/390/430/768/1280px 布局。
- 模拟短视口 320×360、展开工具时，终端由修改前约 4px 提高到约 64px；390×320 下约 72px。普通手机视口及桌面检查无横向溢出。
- 补充 35 项隔离浏览器检查通过，涵盖会话面板边界、关闭与焦点、剪贴板等待/编辑/取消/权限失败/空数据、断线恢复不自动粘贴、控制字符防绕过和查找的可访问名称。两组共 92 项通过；会话回归、Web UX、类型检查和生产构建通过。已查看手机切换面板和粘贴面板截图。
- 未调用真实 Agent 或模型；真实 Codex 询问解析、手机实机软键盘、Safari、安全区和读屏全流程尚未验收。不宣称已覆盖所有组合键。

## 重跑浏览器检查

运行 `npm run build`。隔离 fixture 需要 Node.js、`ws` 测试工具及 Playwright CLI；`ws` 仅用于手工验收，未加入产品依赖。若该工具不在项目可解析的模块目录，通过 `CODEGATE_FIXTURE_WS_MODULE` 指定现有 `ws/wrapper.mjs` 的文件 URL。

从仓库根目录运行 `node web/tests/mobile-terminal-fixture.mjs web/dist`，打开 `http://127.0.0.1:4198/sessions/00000002-1111-4111-8111-111111111111`，再用 Playwright CLI 的 `run-code --filename` 执行 `web/tests/mobile-terminal-browser.js`。fixture 只在本机 4198 端口提供模拟设备，不连接生产服务。

同一 fixture 下执行 `web/tests/mobile-terminal-ux-browser.js` 可重跑补充审查；剪贴板只返回测试文字，不读取操作系统的真实剪贴板。
