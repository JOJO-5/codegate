# v0.1.44：确认后立即关闭任务并重启 Agent

本次新增确认后立即关闭任务并重启升级 Agent 的入口。没有数据库迁移。以下记录实现范围及本地验证；实际部署、产物校验及 Agent 切换状态以发布记录为准。

## 用户路径和影响

设备页 → Agent 更新 → **立即关闭任务并重启升级**。原有“空闲时重启并升级”保留。

第一次点击只打开确认框，显示设备、当前/目标版本、终端与操作数量以及 DSH Web 的影响。默认焦点在“取消”，支持 Escape、Tab 焦点约束及关闭后焦点返回。第二次明确确认才请求关闭；界面和 Server、Agent 都绑定当前实例，旧确认不能作用于重启后的新实例。

Agent 先检查和校验更新包，失败时保持现有工作；没有新版时重启当前版本。准备阶段可取消重启安排，进入停止阶段后不能撤销。然后阻止新操作进入，取消当前后台执行、主 Agent 调度和续跑监测，关闭受管终端、上传与 DSH Web；Git/工作区操作使用可取消的本机上下文。尚未开始的未来预约保留。

已保存文件、原生历史、工作区与执行回执保留。未保存输入、终端回看缓冲和进程内存不保留。共享 Codex/OpenCode 服务本身不结束：只停止当前受管终端绑定的工作，历史续跑回执只能中断其明确记录的自有回合，不能借旧回执停止其他入口新开的回合。未确认停止、超时、身份/目录不匹配或不能保存回执时，不继续重启，显示失败和核对/重试入口。

## 真实反馈、恢复与兼容

- 202 只表示受理，不显示“升级成功”；区分检查、停止、切换及重新上线。只有观察到更新的实例及实际版本才核对结果，旧缓存实例不作为成功证据，回退旧版会明确提示。
- 发请求前将有限的操作意图保存到当前账号/设备的 sessionStorage；刷新、断线或应答丢失后只核对状态，不自动重放关闭命令。设备切换/组件销毁后丢弃迟到应答。
- 停止结果保存到本机回执，并在退出前刷新发送队列；连接失效时新 Agent 仍可根据回执回答核对。任务查询在关闭阶段只返回停止中/已有结果，不再改写原生控制状态。
- Server 校验设备归属、显式确认、能力和实例，不能由浏览器伪造回执属主。旧版 Agent 禁用立即重启并说明原因，需要先完成一次普通升级；此功能不会对旧版静默降级为其他关闭策略。

这次落实可发现的目标命名、设备与影响映射、默认取消、防误触、真实阶段反馈，以及断线后不盲目重放的恢复路径；没有把退出进程和升级验收混为一谈。

## 验证

- Go 测试覆盖确认/归属/旧版能力/过期实例、下载失败不停止工作、拒绝新任务、实际受管终端关闭且文件保留、原生停止确认、停止超时、旧监测不打断新外部回合、取消回执持久化与查询不覆盖，以及重复请求不重复执行。
- 本机 Agent、Server、Session、Protocol、Supervisor 与 Processutil 包测试和 vet；Web UX 回归、类型检查与生产构建。
- 隔离浏览器 fixture 对真实 Vue 组件测试：320px、确认前不发送、默认取消、Escape/Enter、Tab/Shift+Tab、过期确认、实例确认载荷、防重复、刷新恢复、观察新实例和旧版门控。服务请求被受控拦截，实际 Agent 操作为 0、模型调用为 0。
- 重跑：`npm run dev -- --host 127.0.0.1 --port 4187 --strictPort`，用 Playwright CLI 打开 `/tests/agent-restart-browser.html`，执行 `run-code --filename web/tests/agent-restart-browser.js`（文件路径应相对 CLI 工作目录解析）。

未验证：线上用户点击后的强制停止与升级、真实模型/DSH 任务的中断、Linux/macOS 实际强制关闭，以及手机实机和读屏全流程。隔离测试通过不代表这些项目已验收。
