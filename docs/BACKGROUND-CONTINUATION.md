# 原生对话后台续跑（v0.1.25）

在设备的已结束 Codex、Claude Code、OpenCode 记录上点击「安排继续」。选择原生历史（已绑定则自动使用）、继续指令、最早执行时间和运行上限。默认最早时间为五小时后，可自行修改。网页可以关闭；Server 保存任务，电脑必须保持开机，Agent 在线。离线设备上线后再执行。

「按时间继续」适合所有受支持的普通 CLI 配置。「到时检查额度」只用于能可靠查询额度的默认配置；所有已知耗尽窗口恢复后才运行。五小时不是所有订阅统一的恢复周期，周限额可能更久。查询失败或自定义 CLI 参数无法核对额度时明确失败，不猜测剩余额度，也不会切到付费 API。

执行使用 Codex `exec resume`、Claude `--print --resume`、OpenCode `run --session`，指令只送 stdin，不拼入 shell 命令。Agent 在启动前核对授权目录、CLI、本机原生历史和是否已有终端/后台任务占用同一对话。不会新建对话代替缺失的历史。CLI 的本机审批策略继续生效，后台执行遇到交互审批可能失败，应回原对话处理。

每次执行有独立身份和本机原子回执；准备标记在进程启动前落盘。Server 重启后查询回执，不重新发送指令。响应丢失时先等待重连核对回执；若 Agent 崩溃留下无法确认的准备/运行回执，则进入「需要确认」；用户核对原生历史后可以重新安排。无法承诺模型或外部工具副作用恰好执行一次。

排队阶段取消立即生效；运行阶段取消会停止 Agent 拥有的整个 CLI 进程树。默认本次上限120分钟，可设1–360分钟；到时停止进程。取消和超时无法撤销已经完成的文件或外部操作。后台任务占用的独立工作区不能被工作区清理功能删除。Agent 更新期间会等待任务结束；Agent 退出时停止并等待任务。运行中恢复同一个原生对话会被拒绝，避免同时写入历史。

Server 每5秒检查到期任务；等待离线设备每60秒复查；运行回执每30秒核对。网页任务列表每15秒刷新。额度面板在可见且网页前台时每30秒自动刷新，Agent额度缓存15秒，网页请求15秒超时。时间不是硬实时保证，查询、网络和启动开销会增加等待。

保存指令和最终模型文本摘要（上限16KiB），不保存 CLI stderr、工具执行日志或整个本机环境。任务通过设备所有权授权，浏览器不能直接发送 Server 的执行指令。每台设备最多20个未结束任务，提交 nonce 防止网络重试重复建任务。列表展示最近200条记录。

当前范围是用户主动安排原对话继续。额度模式在启动前等待已知阻塞窗口；若后台 CLI 失败后再次查询明确确认额度耗尽，会在重置后恢复同一原生对话，最多3次实际运行。普通错误或无法核实额度时不重发。尚未实现对所有交互终端的持续额度墙检测、目标完成判定和主模型调度。执行状态「本次执行结束」只代表 CLI 正常结束，用户仍需核对结果。
